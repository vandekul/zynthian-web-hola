Esta es una colección de plugins creada sobre las extensiones dRowAudio para JUCE. dRowAudio es un módulo JUCE de terceros diseñado para desarrollar aplicaciones de audio rápidamente. Contiene clases para el procesamiento de audio y elementos de interfaz gráfica. Además, incluye varios wrappers para bibliotecas de terceros, como cURL, FFTReal y SoundTouch. dRowAudio está escrito siguiendo estrictamente el estilo JUCE y la guía de estilo establecida en JUCE Coding Standards.

## Descripción general del plugin

#### Tremolo
Este efecto de tremolo se puede utilizar tanto en modo mono como estéreo y cuenta con todas las funciones que cabría esperar. Se pueden ajustar la velocidad y la profundidad, así como la forma de onda y la diferencia de fase entre los canales izquierdo y derecho. También incluye una visualización en tiempo real de la forma de onda de modulación para que puedas ver exactamente el efecto que produce el tremolo..

#### Distortion Shaper
Se trata de un Distortion altamente configurable con una función de transferencia definida por el usuario. Esto significa que puedes controlar tú mismo la curva utilizada para definir la distorsión mediante dos puntos en el gráfico. Esto permite crear sonidos de distorsión extremadamente personalizados..

Tanto los input y output gains se pueden controlar, al igual que los sencillos low-pass filters pre y post distorsión, para personalizar aún más la distorsión y eliminar las frecuencias altas ásperas si es necesario..

#### Reverb
Esta es una Reverb altamente configurable basada en el modelo de Schoeder/Moorer. Incluye controles para ajustar Pre-delay, Early Reflections y Late Reverb, así como varios parámetros de sala, como la forma, la absorción y la difusión.

#### Flanger
Este es un efecto flanger estéreo. Tiene un amplio rango de intensidad y una cantidad de feedback ajustable para conseguir efectos extremos. También incluye un control de mezcla de salida para ajustar cuánto efecto se aplica a la pista..

#### Distorsión
Este es un sencillo efecto de distorsión que puede usarse en modo mono o estéreo. Tiene controles para filtrar antes y después de la distorsión, además de un control de color para ajustar la forma de onda..
