Esta é uma coleção de plugins criada com base nas extensões dRowAudio para JUCE. dRowAudio é um módulo JUCE de terceiros, desenvolvido para a criação rápida de aplicações de áudio. Ele contém classes para processamento de áudio e elementos de GUI. Além disso, inclui vários wrappers para bibliotecas de terceiros, incluindo cURL, FFTReal e SoundTouch. dRowAudio segue o estilo estrito do JUCE, acompanhando de perto o guia de estilo estabelecido em JUCE Coding Standards..

## Visão geral do plugin

#### Tremolo
Este efeito de tremolo pode ser usado nos modos mono ou estéreo e tem todos os recursos que você esperaria. A taxa e a profundidade são ajustáveis, assim como a forma de onda e a diferença de fase entre os canais esquerdo e direito. Também há uma exibição da forma de onda de modulação em tempo real, para que você possa ver exatamente o efeito visual do tremolo..

#### Distortion Shaper
Este é um Distortion altamente configurável com uma função de transferência definida pelo usuário. Isso significa que você pode controlar a curva usada para definir a distorção usando dois pontos no gráfico. Isso permite criar sons de distorção extremamente personalizados..

Tanto os Gains de entrada e saída são controláveis, assim como simples filtros low-pass antes e depois da distorção para personalizar ainda mais a distorção e remover frequências agudas desagradáveis, se necessário..

#### Reverb
Este é um Reverb altamente configurável baseado no modelo Schoeder/Moorer. Inclui controles para ajustar Pre-delay, Early Reflections e Late Reverb, bem como vários parâmetros da sala, como formato, absorção e difusão..

#### Flanger
Este é um efeito de flanger estéreo. Ele oferece uma ampla faixa de intensidade e quantidade de feedback ajustável para efeitos extremos. Também há um controle de mixagem de saída para ajustar quanto do efeito é aplicado à faixa..

#### Distortion
Este é um efeito de distorção simples que pode ser usado nos modos mono ou estéreo. Ele tem controles para filtragem pré e pós-distorção, além de um controle de cor para ajustar a forma de onda.
