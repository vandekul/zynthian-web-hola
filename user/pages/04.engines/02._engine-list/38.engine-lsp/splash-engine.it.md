LSP (Linux Studio Plugins) è una raccolta di plugin open source progettati per colmare la carenza di plugin validi e utili sulla piattaforma GNU/Linux..

Dopo alcuni contributi ad altri progetti open source, si è deciso di realizzare una distribuzione indipendente di plugin..

Attualmente il progetto è sviluppato e mantenuto dal LSP Project Team, con il fondatore principale e sviluppatore a capo – Vladimir Sadovnikov.
