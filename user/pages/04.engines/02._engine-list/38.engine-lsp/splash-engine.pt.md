LSP (Linux Studio Plugins) é uma coleção de plugins de código aberto projetada para suprir a falta de plugins bons e úteis na plataforma GNU/Linux..

Após algumas contribuições para outros projetos de código aberto, decidiu-se implementar uma distribuição independente de plugins.

Atualmente, o projeto é desenvolvido e mantido pela equipe do Projeto LSP, com o principal fundador e desenvolvedor à frente – Vladimir Sadovnikov.
