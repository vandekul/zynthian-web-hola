Um efeito de Chorus inspirado no encontrado em certos sintetizadores analógicos vintage japoneses bem conhecidos (Você Sabe quais).

Mecanismo DSP de Chorus retirado do sintetizador de software TAL Noisemaker, de Patrick Kunz, Togu Audio Line, Inc., lançado sob a licença GPL-2.0.

Compile usando o DISTRHO Plugin Framework (DPF) e configure com o modelo de projeto cookiecutter-dpf-effect.
