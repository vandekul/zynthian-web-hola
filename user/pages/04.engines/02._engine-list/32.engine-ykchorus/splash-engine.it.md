Un effetto Chorus ispirato a quello presente in alcuni noti sintetizzatori analogici vintage giapponesi (Sai quale).

Motore DSP Chorus tratto dal sintetizzatore software TAL Noisemaker di Patrick Kunz, Togu Audio Line, Inc., rilasciato con licenza GPL-2.0.

Compila usando il DISTRHO Plugin Framework (DPF) e configura il progetto con il template cookiecutter-dpf-effect.
