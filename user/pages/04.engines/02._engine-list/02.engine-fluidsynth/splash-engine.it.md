FluidSynth è un sintetizzatore software in tempo reale basato sulle specifiche SoundFont-2 e si è diffuso ampiamente. FluidSynth non dispone di un'interfaccia grafica, ma grazie alla sua potente API viene utilizzato da diverse applicazioni, è persino approdato nei sistemi embedded ed è usato in alcune app per dispositivi mobili.

## Funzionalità:
+ Supporto multipiattaforma (Linux, macOS e Windows per citarne alcuni)
+ Supporto per SoundFont 2
+ Supporto per SoundFont 3 (SF2 compresso con vorbis)
+ Controllo degli effetti in tempo reale tramite i modulatori SoundFont 2.01
+ Supporto limitato per Downloadable Sounds (DLS) Livello 1 & 2
+ Riproduzione di file MIDI
+ Libreria condivisa che può essere utilizzata in altri programmi
+ Shell a riga di comando integrata
