AIDA-X è un Amp Model Player che permette di caricare modelli di apparecchiature musicali addestrati con l'IA, che puoi poi suonare.!

Il suo uso principale previsto è fornire simulazioni ad alta fedeltà di amplificatori. Tuttavia, è anche possibile utilizzare intere catene di segnale composte da qualsiasi combinazione di amplificatore, cabinet, distorsione, drive, fuzz, boost ed EQ..

#### Ottieni modelli da una grande community

[Tone3000.com](https://tone3000.com/) è diventato il luogo ideale per trovare i migliori modelli per Neural Amp Modeler, Aida-X e Proteus, continuando a espandere il supporto per altre piattaforme in futuro. Non solo modelli: anche la nostra raccolta di IRs sta crescendo e sta diventando molto popolare sulla piattaforma.

#### Caricamento dei file
AIDA-X include un Amp Model e un Cabinet IR integrati. Fai clic sul nome del file corrispondente per aprire un browser di file e caricare un file diverso.
La piccola icona sul lato sinistro consente di attivare/disattivare Amp Model e Cabinet IR. Sono supportati i formati audio wav e flac per i file IR..

Dalla zynthian-ui puoi anche caricare facilmente i file model e IR. Basta ruotare la manopola assegnata ai controlli model o IR e comparirà il selettore di file..
