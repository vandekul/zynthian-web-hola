Guitarix est un amplificateur de guitare virtuel pour Linux fonctionnant avec Jack Audio Connection Kit. Il est libre comme dans liberté et gratuit comme dans bière. Le code source disponible permet également de le compiler sur d'autres systèmes de type UNIX, notamment BSD et MacOSX..

Guitarix prend le signal de votre guitare comme le ferait n’importe quel ampli : sous forme de signal mono provenant de votre carte son. Le signal d’entrée est traité par un ampli principal et une section rack. Les deux peuvent être routés séparément et délivrent un signal stéréo traité via Jack. Vous pouvez remplir le rack avec des effets provenant de plus de 25 modules intégrés, allant d’un simple noise gate à des effets de modulation qui vous retournent le cerveau, comme le flanger, le phaser ou l’auto-wah..

Votre signal est traité avec une latence minimale. Sur tout système Linux correctement configuré, vous n'avez pas à attendre plus de 10ms pour que votre son soit traité par guitarix..
